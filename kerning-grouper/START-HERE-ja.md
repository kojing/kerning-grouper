# Kerning Grouper v0.5 引き継ぎパッケージ

- 開発を別のAIに引き継ぐ：`DEVELOPMENT-PROMPT-ja.md` の全文と、このZIP内のソースを渡してください。
- 手元で試す：ZIPを展開し、`standalone.html` を開いて `samples/KGJapaneseTest-Regular.ttf` を読み込みます。
- 和文テスト：タブ「1 対象グリフ」でひらがな・カタカナ・和文の約物の規則にチェック（英大文字などは外す）→「2 グループ作成」で必要なら「統合の強さ」を40にして「グループを作成」→「3 グループ調整」で分離・統合・固定→「4 カーニング生成」で「カーニング生成」→「5 カーニング調整」で個別に直し、「6 保存」で書き出し。前の手順が済んでいないタブは無効表示になり、何をすればよいかを表示します。右の表（グループ単位／グリフ単位）と上部の校正プレビューで確認しながら、左のタブで調整できます。英大文字などの規則にチェックを入れると和欧混在でも試せます。外したい文字は「除外する文字」に、和文と欧文などの組み合わせをカーニングするかは「領域ごとの組み合わせ」の表で決めます。漢字は含みません。
- Confluenceで使う：`kerning-grouper.js` を社内で配信し、`confluence-macro.html` の `MAIN_JS_URL` をそのURLに変更してHTMLマクロへ貼り付けます。
- 開発する：`npm ci` と `npm run build`。詳しくは `README.md`。

FontLab 用 VFM（グリフ単位のペア）を書き出せます（v0.5.3）。OTF/AFM の書き換えは未実装です。容量はモデル概算です。
