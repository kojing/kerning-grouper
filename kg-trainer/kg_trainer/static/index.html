Kerning Grouper

学習ツール

プロのフォントのカーニングから、計算の設定と補正モデルを学習します。データはこのPCの外に出ません。
core —

対象の字

基準と最小の字間は Web 版の初期値と同じです。学習で決まるのは光学の割合・種類ごとの字間・上限と、その残りの補正です。

各フォントのカーニング（正解）として読み取れた内容です。kern 機能の PairPos（クラス・個別・拡張ルックアップ）と、なければ旧 kern テーブルを読みます。

Web 版の値の補正モデル（欧文）

英字どうしのペアで、Web 版が付ける値の大きさを、ここで使うフォントから学習し直します。書き出した kern-model.js を Web 版の src/kern-model.js と差し替えてビルドすると反映されます。

プロのカーニングクラスを「同じグループにすべき字の組」とみなし、グループ作成の判定がどれだけ一致するかを、強さと許容の倍率を変えて調べます。

ローカル実行（127.0.0.1）。学習に使えるのは、ライセンス上許されたフォント（OFL や自社フォントなど）だけです。
